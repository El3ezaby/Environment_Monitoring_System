# 🔬 IV Characteristics Measurement System

A complete embedded system solution for measuring the **Current-Voltage (IV) characteristics** of diodes under different operating conditions using a custom-designed hardware platform and a Python desktop application.

---

# 🚀 Project Overview

This project was developed to measure and analyze the IV characteristics of semiconductor diodes in both:

- Forward Bias
- Reverse Bias

The system also supports applying different light sources during reverse bias testing to study the effect of light on diode behavior.

Supported light sources:
- UV LEDs
- IR LEDs
- RGB LEDs

The project combines:
- Embedded Systems
- PCB Design
- Desktop Application Development
- Serial Communication
- Real-Time Measurement Systems

# 💻 Python Desktop Application

A desktop GUI application was developed using Python to communicate with the embedded hardware.

## GUI Features
- Forward bias measurement
- Reverse bias measurement
- Instantaneous value display
- Real-time monitoring
- Serial Port communication
- User-friendly interface

---

# 🔗 Communication Protocol

The system uses:
- UART Serial Communication

Between:
- ATMEGA32
- Python Desktop Application

This enables seamless and fast data transfer between the hardware and software.
